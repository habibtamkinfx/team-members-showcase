# 🧑‍🤝‍🧑 Team Members Showcase

A modern, responsive and visually appealing **Team Members Showcase** built with **HTML5 & CSS3**.  
This project demonstrates clean UI design, advanced hover effects, CSS variables, and fully responsive layout using CSS Grid.


2. Open `index.html` in your browser

---

## 🎨 Customization

You can easily customize:

- 🎨 Colors → inside `:root` variables in CSS
- 👤 Team members → edit HTML cards
- 🖼️ Images → replace URLs with your own
- 🔗 Social links → update `href` in icons

---

## 📌 Font Awesome Integration

This project uses Font Awesome CDN:

```html
<link
  rel="stylesheet"
  href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.0.1/css/all.min.css"
/>
```
